# Cloudflare R2 — image storage (production)

R2 replaces **EFS `/uploads`** for scan images, masks, and attachments. The app still serves files through **`GET /api/files/...`** (session auth); objects live in R2 behind the scenes.

---

## 1) Create bucket (Cloudflare dashboard)

1. **R2** → **Create bucket**
2. **Name:** e.g. `skinfit-uploads-prod` (permanent)
3. **Location:** Automatic or **Asia Pacific** (Mumbai users)
4. **Storage class:** Standard
5. Create

Bucket stays **private** — the app uses API keys server-side (no public bucket URL required for v1).

---

## 2) API token

1. **R2** → **Manage R2 API Tokens** → **Create API token**
2. Permissions: **Object Read & Write** on your bucket (or account-level for dev)
3. Copy:
   - **Access Key ID**
   - **Secret Access Key**
4. **Account ID** — from R2 overview URL or dashboard sidebar

---

## 3) Environment variables

Set on **`skinfit-web`** and **`ml-worker`** ECS tasks (and local `.env.local` to test):

| Variable | Example |
|----------|---------|
| `STORAGE_DRIVER` | `r2` |
| `R2_ACCOUNT_ID` | Cloudflare account ID |
| `R2_ACCESS_KEY_ID` | From API token |
| `R2_SECRET_ACCESS_KEY` | From API token |
| `R2_BUCKET_NAME` | `skinfit-uploads-prod` |
| `R2_ENDPOINT` | Optional — default `https://<R2_ACCOUNT_ID>.r2.cloudflarestorage.com` |

Keep using:

| Variable | Value |
|----------|--------|
| `PUBLIC_UPLOAD_BASE_URL` | `http://<ALB-DNS>/api/files` (or `https://...` after TLS) |

**Remove or stop using** on production when fully on R2:

- `LOCAL_STORAGE_ROOT` (not used when `STORAGE_DRIVER=r2`)
- EFS mount **`/uploads`** on web/worker (optional after migration)

**Do not commit** secrets to git — ECS task env or Secrets Manager.

---

## 5) Existing scans on EFS

Files already on **EFS `/uploads`** are **not** in R2 automatically.

| Approach | When |
|----------|------|
| **New scans only** | Flip `STORAGE_DRIVER=r2`; old reports keep using EFS until you migrate |
| **Migrate** | Copy `uploads/scans`, `uploads/masks`, etc. into R2 with same keys (`scans/uuid.jpg`) |
| **Hybrid** | Keep `STORAGE_DRIVER=local` + EFS until migration script is run |

---

## 6) Test

1. Submit a **new** scan on ALB
2. Worker completes → DB stores path `scans/<uuid>.jpg`
3. Report images load via `/api/files/scans/...`
4. Cloudflare R2 dashboard → bucket shows new objects under `scans/`, `masks/`

## Local dev with R2

```bash
# .env.local
STORAGE_DRIVER=r2
R2_ACCOUNT_ID=...
R2_ACCESS_KEY_ID=...
R2_SECRET_ACCESS_KEY=...
R2_BUCKET_NAME=skinfit-uploads-dev
PUBLIC_UPLOAD_BASE_URL=http://localhost:3000/api/files
```

Run `npm run dev` + `npm run worker:dev` with the same R2 vars.
